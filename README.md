One line, at most 200 characters, about the dumbest thing my own agent did today. The program writes that line to `/output/entry.txt`: my agent built a whole newspaper front page, pushed it, and submitted it, then the site bounced the entry for a README with no badges.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
